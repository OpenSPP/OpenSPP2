Provides analytics dashboards for farmer registry data using Odoo's spreadsheet dashboard framework. Displays CEL-based metrics covering farm counts, activity summaries, and agricultural trends for program monitoring and decision-making.

### Key Features

- Farmer Registry Overview dashboard with key metrics
- CEL-based metric calculations for farm and activity aggregations
- Spreadsheet dashboard integration for interactive data exploration
- Role-based dashboard access control (farm managers, admins)
