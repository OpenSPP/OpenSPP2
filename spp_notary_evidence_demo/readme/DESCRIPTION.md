Demo Registry Notary providers, claims, sample registrants, and CEL-driven
programs for the hosted Registry Lab stack. Fresh installs seed the hosted lab
URLs and public demo credentials by default.

The demo seeds three programs using explicit Notary evidence paths:

- `r.evidence.registry_lab_civil_notary.person_is_alive`
- `r.evidence.registry_lab_shared_eligibility_notary.eligible_for_combined_support`
- `r.evidence.registry_lab_shared_eligibility_notary.health_service_available`

A healthy lab-backed run evaluates ten personas across the three programs and
returns `30 passed, 0 failed, 0 errors, 0 skipped`.
