# Changelog

All notable changes to the OpenSPP Vocabularies will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2024-01-15

### Added

- Initial release with 10 vocabulary files
- ISO 3166-1 Country Codes (252 codes)
- ISO 639-1 Language Codes (186 codes)
- ISO 4217 Currency Codes (179 codes)
- ISO 5218 Gender Codes (4 codes)
- ISCED 2011 Education Levels (10 codes)
- ISCO-08 Occupation Classification (10 major groups)
- UN Marital Status (6 codes)
- Washington Group Disability Domains (6 codes)
- Washington Group Severity Levels (4 codes)
- Religion codes (10 codes)

### Infrastructure

- JSON Schema for vocabulary validation
- Fetch scripts for ISO 3166, 639, and 4217
- Validation script for schema compliance
- Automated fetch_all.py script
