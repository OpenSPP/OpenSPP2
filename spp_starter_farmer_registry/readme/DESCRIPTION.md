All-in-one starter package that bundles the complete farmer registry with land management, GIS capabilities, FAO-aligned vocabularies, and program support into a single installable module. Built on top of the social registry foundation.

### Included Components

- **Farmer Registry** (`spp_farmer_registry`) — core farm data, activities, and CEL variables
- **Vocabularies** (`spp_farmer_registry_vocabularies`) — FAO-aligned crops, livestock, and aquaculture classifications
- **Land Records** (`spp_land_record`) — land parcel management with GIS
- **Irrigation** (`spp_irrigation`) — irrigation infrastructure tracking
- **GIS** (`spp_gis`) — geographic data and mapping
- **Programs** (`spp_programs`) — social protection programs with entitlements
- **Social Registry Foundation** (via `spp_starter_social_registry`) — registry, security, area, and vocabulary base
