OpenSPP Branding Kit

Branding customization, URL routing and telemetry management for OpenSPP

Overview

Replaces Odoo branding with OpenSPP branding across the platform. Adds /openspp URL routing as an alias for /odoo routes, redirects telemetry to OpenSPP endpoints or disables it entirely, and customizes system messages, email signatures, and report footers. Works with theme_openspp_muk for visual styling.

Key Features

URL Routing

/openspp/programs/123 works as an alias for /odoo/programs/123. Both routes remain functional.

Telemetry Control

Redirect telemetry to an OpenSPP endpoint or disable it entirely via Settings.

Session Branding

Injects OpenSPP system name and version into the web client session for consistent UI branding.

Report Customization

Updates company report headers and footers with OpenSPP text during installation.

Debug Restriction

Optionally restricts debug mode access to administrators only.

Module Filtering

Adds an "OpenSPP Apps" filter and dedicated menu to browse OpenSPP-specific applications.

Configuration

  1. Open Settings
  2. Scroll to the OpenSPP Branding app card
  3. Configure System Name (default: "OpenSPP Platform")
  4. Set Documentation URL and Support URL
  5. Toggle Display OpenSPP Branding to show/hide "Powered by OpenSPP"
  6. Configure telemetry: enable (redirects to OpenSPP endpoint) or disable
  7. Set Telemetry Endpoint if redirecting

Post-install hook automatically disables Odoo brand promotion, module update notifications, and theme store menu.
