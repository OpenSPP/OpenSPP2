OpenSPP Claim 169 QR Credentials

MOSIP Claim 169 QR code identity credentials

Features

  • Configurable attribute mapping from OpenSPP fields to Claim 169 attributes
  • CWT (CBOR Web Token) generation with COSE Sign1 signatures
  • QR code generation with zlib compression and Base45 encoding
  • Integration with OpenSPP registry (res.partner)
  • Credential storage, tracking, and revocation
  • Multi-issuer support
