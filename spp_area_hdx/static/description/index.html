OpenSPP HDX COD Integration

Alpha LGPL-3

Integration with the Humanitarian Data Exchange (HDX) for downloading Common Operational Datasets (COD) for administrative boundaries with polygons.

Supports humanitarian coordination with P-code standardization and GPS-based area lookup using PostGIS spatial queries.

Features

  • HDX COD Registry - Maintain registry of COD datasets for different countries
  • Dual Import Modes - Download from HDX API or upload GeoJSON files manually
  • Auto Field Detection - Automatically detect P-code and name fields from GeoJSON
  • GPS-based Lookup - Find areas by GPS coordinates using PostGIS ST_Contains
  • P-code Standardization - Support for official P-codes from humanitarian coordination
  • Polygon Import - Import admin boundary polygons for GIS visualization
  • Hierarchical Matching - Find parent areas using P-code relationships
  • Batch Processing - Import large datasets with batched commits

Quick Start

1. Sync COD Sources

Navigate to OpenSPP > Area > HDX Integration > COD Sources

Click Sync from HDX on a country to fetch available admin levels

2. Import COD Data

Navigate to OpenSPP > Area > HDX Integration > Import COD

Select import mode (HDX or File), configure options, preview and import

3. GPS Lookup

# Find area containing GPS coordinates area = env['spp.area'].find_by_coordinates( latitude=6.927079, longitude=79.861244 ) # Find all containing areas (hierarchy) areas = env['spp.area'].find_all_containing( latitude=6.927079, longitude=79.861244 ) # Find by P-code area = env['spp.area'].find_by_pcode('LK3101')
