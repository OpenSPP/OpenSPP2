Provides FAO-aligned vocabularies for agricultural classification and enables bulk import of AGROVOC standard vocabularies via RDF. Ships with pre-loaded vocabularies for crops (FAO ICC 1.1), livestock (FAO 2020), and aquaculture species (FAO ASFIS 2024).

### Key Features

- AGROVOC RDF import wizard with concept filtering (all, under root concept, specific list)
- Multilingual label extraction with parent-child hierarchy preservation
- Pre-loaded vocabularies: crops, livestock, aquaculture species, farm types, land tenure, cultivation methods, activity purposes, holder types, irrigation assets
- Well-known AGROVOC root concepts for guided import (cereals, livestock, fish, irrigation, etc.)
- Job-worker integration for scalable batch processing of large vocabularies
